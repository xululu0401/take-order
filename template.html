你自己的账

抽成填你对账看到的实际比例（订单价里平台拿走的那部分）。每公里成本是油费或电费，加上折旧、保养、保险摊到每公里，自己估一个数。空车车速只用来把接驾和回空的公里换成分钟。目标时薪是扣完抽成和车钱以后，你觉得一小时至少要落袋多少。

弹出来的单

接驾是从你现在的位置开到上车点的公里；行程的公里和分钟看订单页面上的预估；回空是送到偏的地方以后、大概率要空车开回来的公里，市区内顺路能接到下一单就填 0。

输入会自动存到这台设备的浏览器里，刷新还在；换设备用 JSON 备份。

  • 到手 = 订单价 × (1 − 抽成%)；车钱 = (接驾 + 行程 + 回空) 公里 × 每公里成本；净赚 = 到手 − 车钱。
  • 用时 = (接驾 + 回空) 公里 ÷ 空车车速 + 行程分钟；每小时净赚 = 净赚 ÷ 用时 × 60；按目标该挣 = 目标时薪 × 用时 ÷ 60。净赚不少于该挣的就算「值」，净赚小于 0 是「倒贴」。
  • 至少要多少钱 = (该挣的 + 车钱) ÷ (1 − 抽成%)；接驾最远多远 = 让净赚正好等于该挣的那个接驾公里，向下取到 0.1 km。
  • 没算的：等单的时间、高峰加价和奖励、平台的真实计价和抽成规则、取消和差评的风险、过路费和停车费。本页不联网，不知道任何平台的规则；默认场景是虚构的，结果是估算。
